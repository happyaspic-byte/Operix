# 방문 점검 준비표

점검 상세의 **방문 준비표**에서 예정일과 담당자, 고객사·사업장과 활성 고객 담당자, 전체 대상 자산, 미해결 작업, 연결 계약, 자산별 최근 완료 점검 및 열람 가능한 자료를 확인합니다. 인쇄 / PDF 저장 버튼으로 현장에서 사용할 수 있습니다. 점검 결과와 준비 항목은 서로 별개입니다.

준비 체크리스트는 점검 수정 권한이 있는 관리자·업무 관리자·기술지원이 변경할 수 있습니다. 기술지원은 배정된 다른 담당자의 점검을 수정할 수 없습니다. 체크 상태는 저장되며 변경자는 감사 기록에 남습니다. 변경자와 변경 시각은 감사 권한이 있는 사용자에게만 표시합니다. 휴지통의 점검은 준비표에서 열 수 없습니다.

계약 현황은 자산에 직접 연결된 계약을 기준으로 합니다. 종료·보관 또는 만료된 계약은 만료, 종료일까지 계약별 사전 알림 일수 이내인 계약은 만료 임박, 무기한 계약은 유효, 기간 미확인은 미확인으로 표시합니다. 이전 점검은 현재 점검 예정일 이전에 예정되었던 완료 점검 중 자산별 최신 기록입니다. 미해결 작업은 해당 고객 또는 대상 자산에 연결된 해결·종결 전 작업입니다.

관련 자료는 이 화면에 표시된 점검·고객·사업장·자산·작업·계약에 직접 연결된 자료 중 기밀등급 열람 권한이 있고 검사가 완료된 자료만 포함합니다. 숨겨진 자료의 개수는 노출하지 않습니다. 자료에 접근하려면 해당 원본 상세 화면을 이용하세요. 출력물에는 고객 연락처와 점검 정보가 포함되므로 보관 및 폐기에 주의하세요.

`GET /api/visit-prep/{id}`는 준비표를 반환하고, `PATCH`는 `item_key`와 불리언 `checked`를 받아 체크리스트를 반환합니다. `db/008_visit_prep.sql`은 준비 체크 상태만 추가하며 기존 점검 데이터는 변경하지 않습니다.
