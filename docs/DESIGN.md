# 화면 디자인 기준

Operix 화면은 Apple 웹사이트의 디자인 언어를 사내 업무 화면에 맞게 옮긴 것입니다. 제품 사진 대신 업무 데이터가 주인공이 되도록 UI는 한 걸음 물러나고, 색·그림자·장식은 최소한으로 씁니다. 모든 값은 `src/app/globals.css`의 `:root` 토큰에서 시작합니다.

## 원칙

- **파치먼트 캔버스 + 흰 카드.** 페이지 바탕은 `--parchment`(#f5f5f7), 내용은 반경 18px 흰 카드(`.panel`, `.stat-card`)에 담고 0.08 투명도 헤어라인만 둡니다.
- **강조색은 액션 블루 하나.** 링크·버튼·선택 상태 등 누를 수 있는 것은 모두 `--primary`(#0066cc)입니다. 어두운 면 위의 링크만 `--primary-on-dark`(#2997ff)를 씁니다.
- **크롬에는 그림자가 없습니다.** 위계는 면의 밝기 변화(밝은 카드 ↔ 어두운 타일)와 반투명 유리 효과로 만듭니다. 그림자는 배경을 가리지 않는 떠 있는 메뉴(검색·알림·내보내기)에만 씁니다.
- **밝음과 어둠의 리듬.** 로그인 첫 화면, 대시보드의 대표 지표, 안내 카드는 어두운 타일(`--tile-1`, `--black`)로 밝은 카드 사이에 리듬을 줍니다.
- **상태 색은 의미로만.** 정상·주의·위험·정보 배지와 상태 막대에만 쓰며 두 번째 강조색으로 쓰지 않습니다.

## 글꼴

- macOS·iOS에서는 시스템 글꼴(SF Pro, Apple SD Gothic Neo)을, 그 밖의 환경에서는 라틴 문자에 **Inter Variable**, 한글에 **Noto Sans KR**을 씁니다.
- 굵기는 400·600·700만 씁니다(500 없음). 제목은 600에 자간을 좁히고(`-0.02em`), 본문은 15px·행간 1.47, 페이지 설명은 17px입니다.
- 숫자 지표와 날짜는 `font-variant-numeric: tabular-nums`로 자릿수를 맞춥니다.

## 구성요소

| 화면 요소 | 적용 방식 |
| --- | --- |
| 상단 표시줄 | 52px 고정, 반투명 파치먼트 + 블러(유리 효과), 경로와 현재 화면 이름 |
| 사이드바 | 밝은 면, 선택 항목은 회색 채움 + 파란 아이콘 |
| 기본 버튼 `.button.primary` | 파란 알약 모양, 누르면 0.95배 축소 |
| 보조 버튼 `.button` | 파란 글자·파란 테두리의 투명 알약 |
| 탭 `.tabs` | iOS 세그먼트 컨트롤 — 회색 트랙 위 흰 선택 칸 |
| 표 | 진주색 머리행, 6% 행 구분선, 마우스를 올리면 행 강조 |
| 대화상자 | 반경 18px, 뒤 화면은 어둡게 흐림 처리 |
| 달력 | 오늘은 파란 알약, 다른 달 날짜는 흐리게, 일정은 왼쪽 파란 막대 |

## 접근성

- 본문·보조 글자와 배지는 WCAG AA(4.5:1)를 만족하도록 색을 골랐습니다. 원본 분석의 #7a7a7a는 흰 바탕에서 4.29:1이라 보조 글자에는 #6e6e73을 씁니다.
- 모든 버튼·링크·요약(`summary`)은 키보드 포커스 시 2px 파란 외곽선이 보입니다.
- 모바일에서는 터치 대상 44px 이상, 입력 글자 16px(확대 방지)을 유지합니다.
- `prefers-reduced-motion`을 켜면 전환 효과를 모두 끕니다.

## 새 화면을 만들 때

1. 색·반경·글꼴 값은 직접 쓰지 말고 토큰을 씁니다.
2. 강조가 필요하면 색을 더하기보다 면을 바꿉니다(흰 카드 → 어두운 타일).
3. 카드·버튼·글자에 그림자를 넣지 않습니다.
4. 같은 화면에서 반경 규칙을 섞지 않습니다(입력란 11px, 카드 18px, 누르는 요소는 알약).
