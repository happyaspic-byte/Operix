# ALM 자산 CSV 가져오기

**자산 관리 → 가져오기**에 ALM에서 내보낸 `alm_asset.csv`를 그대로 올립니다. 열 이름이 `display_name`, `serial_number`, `u_asset_type`, `account`, `location.u_city_state_county_country_combined`이면 ALM 양식으로 인식하고 매핑을 자동으로 채웁니다.

## 처리 규칙

| 항목 | 동작 |
| --- | --- |
| 식별 | 시리얼(`serial_number`)로 기존 자산을 찾고, 없으면 표시 이름 앞의 ALM ID(`ee-51066 - …`의 `ee-51066`)를 자산 ID로 찾습니다. |
| 의미 없는 시리얼 | `|`처럼 글자·숫자가 없는 시리얼은 비우고 ALM ID를 자산 ID로 씁니다. |
| 기존 자산 | 자산명·사업장·제품은 유지합니다. 비어 있는 시리얼을 채우고 ALM 원본 값(고객사·위치·유형·지원 권한·만료일·시스템명)을 메모에 추가합니다. |
| 새 자산 | 표시 이름을 자산명으로, 상태는 `unknown`, **사업장 미지정**으로 등록합니다. 고객사·사업장은 자동으로 만들지 않습니다. |
| 제품 | 표시 이름의 제품군(everRun, ztC Endurance, ztC Edge)을 우선하고, 없으면 `u_asset_type`을 변환합니다. ALM이 ztC Endurance를 `windows`로 표기해도 ztC Endurance로 저장합니다. |
| 다시 가져오기 | 같은 파일을 다시 올리면 새로 만들지 않고 갱신만 합니다. |

## 사업장 연결

미리보기에서 원본 고객사·위치 묶음별로 사업장을 선택할 수 있습니다. 선택하지 않으면 사업장 미지정으로 들어가며, 나중에 자산 상세에서 사업장을 지정하면 됩니다. 이미 사업장이 있는 자산은 ALM 가져오기로 사업장을 바꿀 수 없습니다.

`account`·`location`은 ALM 원본 표기일 뿐 실제 소속으로 자동 연결하지 않습니다. 원본 값은 메모에서 확인할 수 있습니다.
