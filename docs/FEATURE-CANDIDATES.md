# 다음 기능 후보

이번 변경은 운영 안정성 보강입니다. 아래는 별도의 기능 제안이며 아직 구현하지 않았습니다.

| 우선순위 | 기능 | 기존 기능과의 관계 | 첫 범위와 확인 기준 |
|---|---|---|---|
| 1 | 방문 점검 준비표 | 기존 반복 점검·일정·자산 목록을 활용 | 방문 전 담당자·자산·미해결 작업·계약 상태·이전 점검 결과를 한 화면에서 확인. 권한 밖 문서는 제외하고, 준비 항목 완료 여부와 변경 시각을 기록 |
| 2 | 근거를 연결한 고객 보고서 초안 | 기존 확정 보고서·관찰/내부 추정/제조사 근거 분류를 활용 | 승인 전 누락 항목 안내와 출처 연결. 내부 추정·제한 문서는 고객 초안에서 제외. 사람이 검토·확정하며 원문 수정이나 자동 발송은 하지 않음 |
| 3 | 자산 변경 이력 비교 | 기존 감사 로그·사업장·장비 정보를 활용 | 날짜별 소프트웨어/구성/상태 차이와 관련 작업을 함께 표시. 고객사 간 이동 제한과 개인정보 파기 정책 유지 |

먼저 방문 준비표를 소수 담당자의 실제 방문 흐름으로 검증하는 것을 권합니다. 첫 구현 전 확인할 내용은 준비에 드는 시간, 현장에서 빠지는 정보, 모바일 사용 여부입니다. 보고서 초안 자동화는 기존 승인·근거 정책을 지킨 상태에서 별도로 설계합니다.
