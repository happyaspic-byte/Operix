# 자산 변경 이력 비교

자산 상세의 **변경 이력**에서 자산과 구성요소, VM의 변경 전후 값을 확인할 수 있습니다. 기간은 한국 시간 기준 날짜이며 양 끝 날짜를 포함합니다. 관련 자산에 현재 연결된 작업과 점검의 생성 시각도 함께 표시합니다. 두 날짜를 선택하면 각 날짜 종료 시점의 기록된 상태와 차이를 비교합니다.

감사 이력 조회 권한이 있는 사용자만 이용할 수 있으며 조회 전용 사용자는 사용할 수 없습니다. 네트워크 등 별도 권한이 필요한 필드는 해당 권한이 있는 사용자에게만 표시합니다. 비밀번호·비밀값·내부 버전 및 생성/수정 시각은 비교하지 않습니다. 연결된 자산에 관한 이력만 표시하며 이동한 구성요소의 다른 자산 내용은 표시하지 않습니다.

변경 전후 값은 이 기능 적용 이후 저장된 감사 기록에서만 확인할 수 있습니다. 기존 감사 기록에는 값이 없어 비교 불가로 표시합니다. 개인정보 파기 대상에 포함된 감사 사본은 파기 표시만 남으며 이전 값을 복원하지 않습니다. 현재 연결 관계를 기준으로 관련 작업을 표시하므로 과거에 연결이 해제된 작업은 표시되지 않을 수 있습니다.


파기된 사본이 있는 자료는 원본에 남아 있을 수 있는 파기 대상 문구가 다시 복사되지 않도록 이후에도 값 스냅샷을 저장하지 않습니다. 이후 변경은 값 비교 불가로 표시합니다.
