# Operix v0.1 검증 결과와 평가

**고객·자산·유지보수 MVP 자체 평가: 83/100.** 아래 검증 근거를 바탕으로 한 개발자 평가이며 외부 인증, 코드 커버리지 또는 타 ERP와의 동등 조건 성능 순위가 아니다. 회계·구매·재고·인사까지 포함한 전사 ERP 완성도 점수로 해석하지 않는다.

검증일: 2026-09-04 UTC / 2026-09-05 한국시간. 모든 화면과 테스트 자료는 가상 데이터다.

## 확인한 업무와 방어 동작

- 고객 → 사업장 → 자산 등록 → 계약 연결 → 점검 완료 → 보고서 확정. 계약 생성은 API, 등록·점검·확정 흐름은 브라우저에서 수행했다.
- 확정 후 원본 점검 내용을 변경해도 기존 보고서의 내용 유지. 인쇄용 한글 PDF 생성.
- 메뉴 이동·새로고침·모바일 메뉴·검색·필터·저장한 필터·표시 열 설정. 390px 화면에서 문서 전체의 가로 넘침 없음.
- 한국시간 경계, 실제 달력 날짜, 만료·당일·무기한·미확인 구분. 월말 기준 반복 일정과 알림 중복 방지.
- 다른 고객사 자산 연결 거부, 대소문자만 다른 자산 ID 중복 방지, 오래된 수정 버전 거부, 일괄 처리 실패 시 롤백.
- XLSX 한글 왕복, CSV 수식 주입 처리, 압축 해제 크기·구조 사전 검사, 가져오기 중복 확정 거부.
- 첨부 파일 원본 바이트 보존, 위장 PNG 거부, 비로그인 다운로드 차단.
- 역할별 서버 권한·민감 필드 제거, 비로그인 요청·다른 출처 변경 요청 차단, 로그인 실패 제한, 사용자 정지와 로그아웃 후 세션 회수.

이 검사는 침투 테스트, 전체 WCAG 준수 인증 또는 운영 부하 시험을 대신하지 않는다. 전체 기능·모든 브라우저·모든 입력 조합을 검증했다는 의미도 아니다.

## 실제 운영으로 넘기기 위해 필요한 항목

실제 사내 Ubuntu 서버의 설치·접속, DNS·HTTPS·VPN·백업 대상, 실자료 이관, 현장 사용자 인수 시험, 운영 부하·장애 복구 시간은 이 작업 환경에서 확인하지 않았다. 실제 고객 자료·서버 접속 환경·사용할 ERP 주소가 확보되어야 해당 작업을 이어갈 수 있다.

사용자 수·자산 수에 따른 성능 산정과 회사 양식의 긴 내용·사진·여러 페이지 출력 확인도 필요하다. 현재 PDF는 브라우저 인쇄 방식이며 첨부는 보고서에서 파일 링크로 제공한다. 외부 메일·메신저 알림, 악성코드 검사 연동, SSO/MFA와 영업·구매·재고·회계·인사는 후속 범위다.

설치 방법은 [운영 가이드](DEPLOYMENT.md), 기성 ERP의 공식 기능 문서와 비교한 결과는 [ERP 비교](COMPARISON.md)에 정리했다.
