# 가져오기 실패 행 내려받기

가져오기 미리보기에서 오류가 있는 경우 실패 행 수와 CSV 또는 XLSX 내려받기 링크가 표시됩니다. 파일에는 실패한 행만 포함되며 앞의 `행 번호`는 업로드한 파일의 실제 행 번호, `오류`는 화면에 표시된 검증 사유입니다. 나머지 열에는 업로드한 값이 포함됩니다. 오류를 수정한 뒤 다시 업로드하고 필요한 열 연결을 다시 지정하세요. `행 번호`와 `오류` 열은 가져올 때 무시됩니다.

CSV는 Excel에서 열 수 있도록 UTF-8 BOM을 포함합니다. CSV에서 수식으로 해석될 수 있는 값은 기존 내보내기와 같이 작은따옴표를 앞에 붙여 보호하므로 해당 값이 실제 데이터인 경우 재가져오기 전에 확인하세요. XLSX의 값은 문자열 셀로 저장됩니다.

다운로드에는 해당 자료의 가져오기 권한과 미리보기를 만든 본인 계정이 필요합니다. 미리보기는 한 시간 동안 유효하며 만료되거나 개인정보 파기로 무효화된 경우 내려받을 수 없습니다. 오류가 있으면 반영 자체가 거부되어 미리보기에서 계속 다운로드할 수 있습니다. 반영이 성공하면 기존 정책대로 원본을 포함한 미리보기 페이로드를 즉시 비우며 다운로드할 수 없습니다. 만료된 미리보기는 정리 작업에서 삭제됩니다. 내려받은 파일은 개인정보를 포함할 수 있으므로 안전하게 보관하고 필요하지 않으면 삭제하세요.
