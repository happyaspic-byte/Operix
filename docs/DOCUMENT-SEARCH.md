# 문서·보고서 복합 검색

문서·보고서 화면에서 고객을 검색해 선택하고 관련 기록 종류, 기밀등급, 날짜 및 파일명·제목을 함께 지정할 수 있습니다. 첨부 자료는 검사 상태로도 좁힐 수 있습니다. 시작일과 종료일은 한국 표준시(KST)의 해당 날짜를 포함합니다. 필터를 바꾸면 첫 페이지부터 표시하며 **필터 초기화**로 조건을 지울 수 있습니다. 검색 조건은 주소에 반영되므로 새로고침하거나 다른 화면에서 뒤로 돌아와도 복원됩니다.

목록과 전체 건수는 현재 사용자가 열람할 수 있는 기밀등급만 포함합니다. 권한이 없는 등급을 API로 지정해도 해당 등급의 존재나 건수를 알려주지 않고 결과 0건을 반환합니다. 파일 다운로드에는 기존 검사 상태와 다운로드 권한 정책이 그대로 적용됩니다. 삭제된 첨부 자료와 철회된 보고서는 검색되지 않습니다.

## API

`GET /api/documents`와 `GET /api/reports`는 기존 페이지네이션 응답 `{ rows, total, page, limit }`을 유지합니다. 검색 조건은 `customer_id`, `entity_kind`, `classification`, `from`, `to`, `uploader_id`, `q`이며 첨부 자료의 검사 상태는 `scan_status`로 지정합니다. 보고서에는 검사 상태가 없으므로 유효한 `scan_status`는 보고서 검색에서 무시합니다. 날짜는 `YYYY-MM-DD` 형식입니다. 보고서의 작성자 조건은 보고서 확정자를 기준으로 합니다. 잘못된 조건은 HTTP 400으로 응답합니다. 고객 조건은 연결된 기록의 고객 관계를 기준으로 합니다.
