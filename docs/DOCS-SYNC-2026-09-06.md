아래 경로는 각 역할 worktree 내부의 무시된 로컬 산출물이다. 저장소 링크로 추가하거나 문서에 원본 로그·trace를 복사하지 않았다. 직접 테스트를 실행한 결과가 아니라 기존 보고서를 읽어 확인한 결과다. JSON의 metadata에는 `actualWorkers`만 있었고 실행 대상 SHA가 없으므로, 조회 커밋에서 실행했다는 확정 근거가 부족하다. 서로 다른 역할의 수치를 더해 통합 통과 개수로 사용하지 않는다.

UI의 `test-results/ui-unblock-20260906/baseline.log`에는 필터 빈 상태의 오래된 기대 문구로 1 failed, `regression.log`에는 11 passed가 기록되어 있다. `test-results/ui-improve/final-ui-tests.log`는 당시 UI 8개 통과 기록이지만 현재 테스트 소스는 9개이므로 최신 전체 UI 검증으로 인용하지 않는다. `domain-tests.log`의 28개 통과, `build-final.log`의 빌드 완료 문구 역시 현재 통합 SHA의 검증 결과가 아니다. `typecheck.log`는 명령만 기록되어 종료 코드 없이 단독으로 성공을 입증하지 못한다.
