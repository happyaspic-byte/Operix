## 환경·권한 설명 대조

[DB 연결](../src/lib/db.ts)은 `DATABASE_URL`이 있으면 PostgreSQL을 사용한다. 없을 때 `OPERIX_EMBEDDED=1`이어야 PGlite를 사용하며 기본 경로는 `.data/operix`다. [worker](../scripts/worker.ts)의 별도 상시 실행에는 PostgreSQL이 필요하다. 내장 DB 시험을 PostgreSQL 검증으로 보고하지 않는다.

[설정 생성기](../scripts/setup-local.mjs)는 `.env`에 로컬 주소, 내장 DB 활성화, 가상 데이터 활성화와 무작위 비밀번호를 기록하고 `PORT`는 생성하지 않는다. 프로세스에 설정된 환경도 별도 확인해야 한다. `UPLOAD_DIR`의 앱 기본값은 `storage/uploads`, Compose 설정은 `/app/storage/uploads`다.

[권한표](../src/lib/policy.ts)는 기본 역할 5개를 코드로 정의한다. 관리자만 `users:write`, 관리자·업무 관리자만 `reports:approve`를 가진다. 네트워크 정보는 관리자·업무 관리자·기술지원, 금액은 관리자·업무 관리자·영업 역할에 허용한다. [계정 API](../src/app/api/settings/route.ts)는 사용자 수정 시 해당 사용자의 세션을 삭제한다. 이는 코드 조사 결과이며 새 권한 회귀 시험 결과는 아니다. 보안 통합 이후 재대조한다.
